# COC场景模板

使用此模板作为新场景文件的基础结构。

---

## 标准场景模板

```
[场景名称]

=== 场景元数据 ===
【所属阶段】第X阶段（初步调查/深入调查/高潮/结局）
【场景类型】并行调查 / 条件触发 / 阶段推进 / 结局
【前置条件】
  - 无 /
  - 需完成场景：XXX
  - 需发现线索：XXX
  - 需处于第X阶段
【可进入次数】1

=== 场景描述 ===

[环境描述 - 氛围、视觉、听觉、嗅觉等感官细节]

[核心内容 - 这个场景的主要事件或调查对象]

=== 调查要素 ===

【观察/侦查】
- 普通观察可见：[描述]
- 成功侦查检定后可见：[描述]

【搜索/调查】
- 可搜索的物品：[描述]
- 搜索结果：[描述]

【其他检定】
- [技能名]检定：[成功/失败的结果]

=== 可发现线索 ===

【线索ID】线索名称
- 发现方式：[如何发现这条线索]
- 线索内容：[线索的具体信息]
- 指向：[这条线索暗示什么/指向哪个场景]

=== NPC（如有）===

【NPC名称】
- 身份：[职业/角色]
- 外观：[简短描述]
- 态度：[对调查员的初始态度]
- 触发条件：[如何让NPC愿意交谈]
- 可提供信息：
  * [信息1]
  * [信息2]
- 隐藏信息（需要特定检定或条件）：
  * [条件]：[信息]

=== 场景事件 ===

【事件1】[事件名称]
- 触发条件：[什么情况下发生]
- 事件描述：[发生了什么]
- 后果：[对调查员的影响]

=== 场景分支 ===

如果调查员[行动描述]：
→ 调用"select_scene"mcp工具，输入参数scenes为"[目标场景名]"

如果调查员[另一行动]：
→ [结果描述]

=== 场景完成条件 ===

本场景的核心调查完成标志：
- [ ] [条件1，如：发现关键线索]
- [ ] [条件2，如：与NPC完成对话]

完成后：调用"discover_clue"工具记录发现的线索。

=== 守秘人笔记 ===

[给GM的提示]
- 氛围营造建议
- 玩家可能的行动及应对
- 与其他场景的联系
- 需要注意的伏笔

=== 离开场景 ===

当调查员完成调查或选择离开时：
- 如果完成核心调查：可正常离开，线索被记录
- 如果未完成：提醒调查员可能遗漏了重要信息（但不阻止离开）

返回后：继续执行主线流程，检查是否满足下一阶段的条件。
```

## 示例：并行调查场景

```
询问附近居民

=== 场景元数据 ===
【所属阶段】第1阶段（初步调查）
【场景类型】并行调查
【前置条件】无
【可进入次数】1

=== 场景描述 ===

墓地附近的住宅不多，只有金博尔家离墓地比较近。步行五分钟范围内能找到几所房屋，空气中弥漫着秋日落叶的气息。

=== 调查要素 ===

【普通询问】
- 邻居们所知甚少，也没有见过任何可疑行迹
- 如果提起道格拉斯·金博尔的名字，有一位邻居会记得他是个和蔼的人

【遇见老妇人】
- 调查员在附近走动时会看见一名老妇人（莉拉·奥黛尔女士）正好经过
- 需要通过外貌(APP)或信用(CR)检定才能与她交谈
- 检定失败：她会快步离开，避开调查员

=== 可发现线索 ===

【线索001】道格拉斯的阅读习惯
- 发现方式：成功与奥黛尔夫人交谈
- 线索内容："大多数日子里都能看见他胳膊下夹着本书走向墓地。他总是在读书。"
- 指向：墓地是重要地点，道格拉斯与墓地有特殊联系

【线索002】道格拉斯的失踪时间
- 发现方式：成功与奥黛尔夫人交谈
- 线索内容：奥黛尔夫人已经有好多年没见过老金博尔了
- 指向：失踪已久，不是近期事件

=== NPC ===

【莉拉·奥黛尔女士】
- 身份：附近居民，老妇人
- 外观：[由GM根据氛围描述]
- 态度：看重外表，对体面的人友善
- 触发条件：外貌(APP)或信用评级(CR)检定成功
- 可提供信息：
  * 道格拉斯总是带书去墓地
  * 很多年没见过他了
  * 知道托马斯继承了房子

=== 场景分支 ===

无特殊分支，完成调查后返回主线。

=== 场景完成条件 ===

- [ ] 与奥黛尔夫人交谈成功，获取道格拉斯的信息
- 或 -
- [ ] 检定失败，无法获取更多信息（场景仍视为已探索）

=== 守秘人笔记 ===

- 这是一个轻量级的信息收集场景
- 主要目的是让玩家了解道格拉斯与墓地的联系
- 即使检定失败，玩家仍可通过其他场景获取类似信息
- 不要在此场景透露食尸鬼相关信息
```

## 示例：条件触发场景

```
如果调查员试图攻击人影

=== 场景元数据 ===
【所属阶段】第2阶段（高潮）
【场景类型】条件触发
【前置条件】
  - 需完成场景：监视屋子或墓地
  - 触发条件：调查员对人影采取攻击行动
【可进入次数】1

=== 场景描述 ===

[战斗场景的详细描述]

=== 战斗规则 ===

【敌人数据】
- 食尸鬼道格拉斯·金博尔
- [属性数据]

【战斗流程】
- [回合制战斗描述]

=== 场景分支 ===

如果调查员成功击败人影：
→ 调用"select_scene"mcp工具，输入参数scenes为"如果调查员成功杀死人影或让它失去行动能力"

如果调查员被击败或逃跑：
→ [描述后果]

=== 守秘人笔记 ===

- 道格拉斯不会主动杀死调查员，除非被逼到绝境
- 如果战斗僵持，道格拉斯可能会尝试交谈
```

## 场景类型速查表

| 类型 | 用途 | 前置条件 | 示例 |
|------|------|----------|------|
| 并行调查 | 可自由选择顺序的调查地点 | 通常无 | 询问邻居、图书馆、查报纸 |
| 条件触发 | 特定行动触发的场景 | 特定玩家行为 | 如果调查员攻击... |
| 阶段推进 | 推动剧情到下一阶段 | 完成前置场景/发现线索 | 监视屋子或墓地 |
| 结局 | 剧本的结束场景 | 完成高潮阶段 | 尾声 |

## 场景命名规范

```
文件名格式：scene{阶段序号}（场景名称）.txt

示例：
scene1（询问附近居民）.txt      # 第1阶段并行场景
scene1（查看墓地周边）.txt      # 第1阶段并行场景
scene2（监视屋子或墓地）.txt    # 第2阶段推进场景
scene3（如果调查员试图攻击人影）.txt  # 条件触发场景
```
