## 项目概述

### 项目简介

COC 跑团游戏系统是一个基于 **LangChain + DeepSeek + FastAPI** 的克苏鲁神话(Call of Cthulhu)角色扮演游戏系统。系统具有以下核心功能：

- **AI 游戏主持人 (GM)**: 使用 DeepSeek 大语言模型作为游戏主持人，与玩家进行自然语言对话
- **骰子检定系统**: 支持标准骰子投掷、属性检定、理智检定
- **场景管理**: 支持多场景切换、场景嵌套、场景进入次数限制
- **角色卡系统**: 从数据库加载调查员属性和技能
- **实时日志**: 完整的日志系统，支持实时查看调试信息

### 运行端口

| 服务 | 端口 | 说明 |
|------|------|------|
| 前端 HTTP 服务 | 5770 | 静态文件服务 |
| 后端统一 API | 5780 | 玩家数据、AI对话、场景管理 |

### DDD 分层架构

项目采用 **领域驱动设计 (DDD)** 分层架构：

| 层级 | 目录 | 职责 |
|------|------|------|
| **适配器层** | `adapter/` | 接收外部请求，提供 API 接口和 CLI 入口 |
| **服务层** | `service/` | 核心业务逻辑，协调领域层和基础设施层 |
| **领域层** | `domain/` | 核心业务模型和领域逻辑 |
| **基础设施层** | `infrastructure/` | 数据库、文件、日志等外部服务 |

```javascript
// 发送到 AI (流式输出)
async sendToAI(message) {
    this.isWaitingAI = true;
    const aiMessageIndex = this.messages.length;

    // 调用 ChatModule.sendMessage
    await ChatModule.sendMessage(
        message,
        // onToken: 每收到一个 token 时更新
        (token) => {
            this.messages[aiMessageIndex].content += token;
        },
        // onComplete: 完成时回调
        async (fullResponse) => {
            this.isWaitingAI = false;
            await this.refreshSceneInfo();
            await this.refreshAvailableScenes();
        },
        // onError: 错误回调
        (error) => { ... }
    );
}
```

### chat.js API 通信模块

`chat.js` 是一个独立的模块，封装了所有与后端的通信：

```javascript
const ChatModule = {
    CHAT_API_URL: 'http://localhost:5780/chat',

    // 检查状态 -> GET /chat/health
    async checkStatus() { ... },

    // 初始化 Agent -> POST /chat/init
    async initAgent() { ... },

    // 发送消息 (流式) -> POST /chat/send
    async sendMessage(message, onToken, onComplete, onError) {
        const response = await fetch(`${this.CHAT_API_URL}/send`, {
            method: 'POST',
            body: JSON.stringify({ message })
        });

        const reader = response.body.getReader();
        // 解析 SSE 格式流式响应
        while (true) {
            const { done, value } = await reader.read();
            if (done) break;

            const chunk = decoder.decode(value);
            const lines = chunk.split('\n');
            for (const line of lines) {
                if (line.startsWith('data: ')) {
                    const content = line.slice(6);
                    if (content === '[DONE]') {
                        onComplete(fullResponse);
                    } else {
                        onToken(content);
                    }
                }
            }
        }
    },

    // 重置记忆 -> POST /chat/reset-all
    async resetAllMemory() { ... },

    // 获取场景信息 -> GET /chat/scene
    async getSceneInfo() { ... },

    // 获取可用场景 -> GET /chat/scenes/available
    async getAvailableScenes() { ... },

    // 进入场景 -> POST /chat/scene/new
    async enterNewScene(scene) { ... },

    // 退出场景 -> POST /chat/scene/exit
```

```python
# 文件: src_test/service/scene_service.py

import uuid
import os
from src_test.domain.models import SceneInfo
from src_test.infrastructure.file import TxtKeywordSearch

# 基础提示词
BASE_PROMPT = """
你是一个克苏鲁神话角色扮演游戏(CoC)的智能游戏主持人(GM)。
"""

SCENE_GUIDANCE = """
在场景中，请遵循以下守则：
- 你是一名游戏的主持人
- 将玩家视为参与该剧本的调查员
- 拒绝玩家进行上帝视角的操作
"""

SCENE_PROMPT = BASE_PROMPT + SCENE_GUIDANCE

# ==================== ThreadManager ====================

class ThreadManager:
    """线程管理器 - 管理场景和记忆线程"""

    def __init__(self, scenes_dir: str = None):
        self.main_thread_id = str(uuid.uuid4())
        self.current_thread_id = self.main_thread_id
        self.scene_stack: list[SceneInfo] = []  # 场景栈
        self.scenes_dir = scenes_dir
        self.txt_search = TxtKeywordSearch(scenes_dir)
        self.main_prompt = self._load_main_prompt()

        # 场景进入次数限制
        self.scene_limits: dict[str, int] = {}
        self.entered_count: dict[str, int] = {}
        self._load_scene_limits()

    @property
    def in_scene(self) -> bool:
        return len(self.scene_stack) > 0

    @property
    def current_scene(self) -> str:
        return self.scene_stack[-1].scene_name if self.scene_stack else ""

    @property
    def scene_depth(self) -> int:
        return len(self.scene_stack)

    def _load_scene_limits(self):
        """从 scenes.txt 加载场景进入次数限制"""
        scenes_file = os.path.join(self.scenes_dir, "scenes.txt")
        with open(scenes_file, 'r', encoding='utf-8') as f:
            for line in f:
                if ':' in line:
                    scene, limit = line.split(':', 1)
                    self.scene_limits[scene.strip()] = int(limit.strip())

    def get_available_scenes(self, ai_returned: list[str] = None) -> list[str]:
        """
        获取可进入的场景列表
        规则: 在 AI 返回的列表中 且 在 scene_limits 中 且 已进入次数 < 可进入次数
        """
        available = []
        for scene, limit in self.scene_limits.items():
            entered = self.entered_count.get(scene, 0)
            if entered < limit:
                if ai_returned is None or scene in ai_returned:
                    available.append(scene)
        return available

    def enter_scene(self, scene: str) -> tuple[str, str]:
        """进入新场景，增加进入次数"""
        # 验证场景是否存在
        if scene not in self.scene_limits:
            raise ValueError(f"无效的场景：{scene}")

        # 检查进入次数限制
        entered = self.entered_count.get(scene, 0)
        if entered >= self.scene_limits[scene]:
            raise ValueError(f"场景进入次数已达上限：{scene}")

        # 增加进入次数
        self.entered_count[scene] = entered + 1

        # 创建新线程
        new_thread_id = str(uuid.uuid4())
        scene_content = self._load_scene_content(scene)
        new_prompt = SCENE_PROMPT + f"\n当前场景：{scene}\n{scene_content}"

        # 推入场景栈
        scene_info = SceneInfo(scene, new_thread_id, new_prompt)
        self.scene_stack.append(scene_info)
        self.current_thread_id = new_thread_id

        return new_thread_id, scene_content

    def exit_scene(self) -> tuple[str, str, str]:
        """退出当前场景"""
        if not self.scene_stack:
            return ("", "主线程", self.main_thread_id)

        exited_scene = self.scene_stack.pop()

        if self.scene_stack:
            # 返回上一层场景
            parent = self.scene_stack[-1]
            self.current_thread_id = parent.thread_id
            return (exited_scene.scene_name, parent.scene_name, parent.thread_id)
        else:
            # 返回主线程
            self.current_thread_id = self.main_thread_id
            return (exited_scene.scene_name, "主线程", self.main_thread_id)

    def get_current_prompt(self) -> str:
        """获取当前提示词"""
        return self.scene_stack[-1].prompt if self.scene_stack else self.main_prompt

    def reset_progress(self):
        """重置场景进度"""
        self.scene_stack.clear()
        self.entered_count.clear()
        self.current_thread_id = self.main_thread_id

# ==================== McpService ====================

class McpService:
    """MCP 服务"""

    def __init__(self, thread_manager: ThreadManager = None):
        self.thread_manager = thread_manager

    def new_scene(self, scene: str) -> str:
        """进入新场景"""
        self.thread_manager.enter_scene(scene)
        return f"已进入场景：{scene}"

    def exit_scene(self) -> str:
        """退出当前场景"""
        exited, return_to, _ = self.thread_manager.exit_scene()
        return f"已退出：{exited}，返回：{return_to}"

    def select_scene(self, scenes: str) -> list[str]:
        """将场景字符串拆分成列表"""
        return scenes.strip().split()
```

```python
from typing import Dict, Any
from src_test.domain.dice import roll
from src_test.infrastructure.database import get_repository

class DiceService:
    """骰子和角色卡相关的核心服务"""

    def __init__(self, repository=None):
        self.repository = repository or get_repository()

    def roll_dice(self, expression: str, is_hidden: bool = False) -> Dict[str, Any]:
        """执行骰子投掷"""
        messages, roll_result = roll(expression)
        return {
            "success": True,
            "result": roll_result,
            "process": messages,
            "is_hidden": is_hidden,
        }

    def roll_attribute_check(self, user_id: str, attribute_name: str) -> Dict[str, Any]:
        """属性或技能检定"""
        player_obj = self.repository.get_user_card(user_id)
        skill_obj = self.repository.get_skill_card(user_id)
        card_data = player_obj.model_dump()
        skill_data = skill_obj.model_dump()

        # 获取目标值
        attribute_id = self.repository.get_id(attribute_name)
        target_value = 0
        if attribute_id in card_data:
            target_value = card_data[attribute_id]
        elif attribute_id in skill_data:
            target_value = skill_data[attribute_id]

        # 投掷 1d100
        messages, roll_result = roll("1d100")

        # 判断成功等级
        success_level = "失败"
        if roll_result <= target_value:
            success_level = "成功"
        if roll_result <= target_value / 2:
            success_level = "困难成功"
        if roll_result <= target_value / 5:
            success_level = "极限成功"
        if roll_result == 1:
            success_level = "大成功"
        if roll_result == 99:
            success_level = "大失败"

        return {
            "属性名": attribute_name,
            "属性值": target_value,
            "骰子值": roll_result,
            "结果": success_level,
        }

    def roll_sanity_check(self, user_id: str, success_penalty: str, failure_penalty: str) -> Dict[str, Any]:
        """理智检定"""
        player_obj = self.repository.get_user_card(user_id)
        card_data = player_obj.model_dump()

        san_id = self.repository.get_id("理智")
        current_san = card_data[san_id]

        # 投掷检定
        messages, roll_result = roll("1d100")
        is_success = roll_result <= current_san

        # 计算理智损失
        penalty_expr = success_penalty if is_success else failure_penalty
        messages_penalty, penalty_result = roll(penalty_expr)
        san_loss = penalty_result

        # 更新数据库
        new_san = current_san - san_loss
        self.repository.set_user_card(user_id, {san_id: new_san})

        return {
            "success": True,
            "check_result": "成功" if is_success else "失败",
            "current_san": current_san,
            "san_loss": san_loss,
            "new_san": new_san
        }
```

```python
# 文件: src_test/domain/dice/roll.py

from src_test.domain.dice.expr import compile

def roll(expr_str: str, op_str: str = None, target_str: str = None):
    """
    执行骰子投掷

    Args:
        expr_str: 骰子表达式，如 "3d6+1d3-1"
        op_str: 比较操作符，如 ">=", "<"
        target_str: 目标值

    Returns:
        (messages, result): 消息列表和最终结果
    """
    messages = []

    # 编译表达式
    expr = compile(expr_str)

    # 投掷
    result, display = expr()

    # 构建消息
    messages.append(f"{expr_str} 投掷结果")

    if isinstance(expr, Roll):
        # 单纯扔一个骰子
        dices = expr.values
        for i, dice in enumerate(dices):
            messages.append(f"第 {i+1} 颗：{dice}")

        if len(dices) > 1:
            messages.append(f"总和 {result}")
    else:
        # 复杂表达式
        messages.append(f"{display} = {result}")

    return messages, result
```

```python
from src_test.domain.models import COCPlayerModel, SkillsModel

class PlayerRepository:
    """玩家数据仓储"""

    def __init__(self, db_connection: DatabaseConnection = None):
        self.db = db_connection or DatabaseConnection()

    def get_user_card(self, user_id: str) -> COCPlayerModel:
        """获取玩家卡片信息"""
        sql_query = f"SELECT * FROM players WHERE id = '{user_id}'"
        results = self.db.execute_query(sql_query)

        if results:
            return COCPlayerModel.model_validate(results[0])
        return None

    def set_user_card(self, user_id: str, update_data: dict) -> bool:
        """更新玩家卡片信息"""
        set_clauses = []
        for key, value in update_data.items():
            if key in ['skills', 'weapons', 'equipments', 'notes']:
                formatted_value = f"'{json.dumps(value, ensure_ascii=False)}'"
            elif isinstance(value, str):
                formatted_value = f"'{value}'"
            elif value is None:
                formatted_value = "NULL"
            else:
                formatted_value = str(value)
            set_clauses.append(f"`{key}` = {formatted_value}")

        sql_query = f"UPDATE players SET {', '.join(set_clauses)} WHERE id = '{user_id}'"
        return self.db.execute_update(sql_query)

    def get_skill_card(self, user_id: str) -> SkillsModel:
        """获取玩家技能卡片信息"""
        sql_query = f"SELECT * FROM skills WHERE id = '{user_id}'"
        results = self.db.execute_query(sql_query)

        if results:
            return SkillsModel.model_validate(results[0])
        return SkillsModel(id=user_id)

    def get_id(self, attribute_name: str) -> str:
        """根据中文名获取属性/技能的 ID"""
        sql_query = f"SELECT id FROM chinese_name WHERE name = '{attribute_name}' LIMIT 1"
        results = self.db.execute_query(sql_query)

        if results:
            return str(results[0]['id'])
        return attribute_name
```

## 核心功能流程

### 1. 系统启动流程

```bash
# 用户执行
cd src_test/front
start.bat

# start.bat 内部
python -m http.server 5770  # 启动前端 HTTP 服务 (端口 5770)
```

### 2. 页面加载流程

```javascript
// game.js mounted() 钩子
mounted() {
    // 1. 检查对话服务状态
    this.checkChatStatus();

    // 2. 定时检查对话服务状态 (每30秒)
    setInterval(() => {
        this.checkChatStatus();
    }, 30000);

    // 3. 恢复登录状态
    const savedToken = localStorage.getItem('authToken');
    const savedPlayerId = localStorage.getItem('playerId');
    if (savedToken && savedPlayerId) {
        this.isLoggedIn = true;
        this.playerId = savedPlayerId;
        this.loadPlayerData();
        this.loadSkillsData();
    }
}
```

### 3. AI 对话完整流程

```
1. 用户输入消息 -> playerInput
2. 点击"发送"按钮 -> sendMessage()
3. 添加玩家消息到 messages 列表
4. 调用 ChatModule.sendMessage()
5. 后端接收 POST /chat/send
6. 清空 available_scenes
7. 获取当前 thread_id
8. 添加消息到 thread_messages[thread_id]
9. 调用 agent.stream() 开始流式生成
10. 每个 token 通过 SSE 格式返回: "data: {token}\n\n"
11. 前端 chat.js 解析 SSE 流
12. 每收到一个 token -> 调用 onToken()
13. 接收完毕 -> "[DONE]" -> 调用 onComplete()
14. onComplete 中:
    - 刷新玩家数据 (loadPlayerData)
    - 刷新场景信息 (refreshSceneInfo)
    - 刷新可用场景 (refreshAvailableScenes)
```

### 4. 场景进入完整流程

```
1. AI 调用 select_scene 工具
2. available_scenes = ["场景A", "场景B"]
3. 前端显示场景按钮
4. 用户点击 "场景A" -> enterScene("场景A")
5. 调用 POST /chat/scene/new { scene: "场景A" }
6. 后端验证:
   - 场景是否在 scene_limits 中
   - 进入次数是否已达上限
7. 增加进入次数: entered_count[场景A]++
8. 创建新线程ID: new_thread_id = uuid()
9. 加载场景文件内容
10. 推入场景栈: scene_stack.append(SceneInfo)
11. 切换当前线程: current_thread_id = new_thread_id
12. 返回响应
13. 前端自动发送 "我已进入当前场景"
14. AI 使用新的提示词和线程生成场景描述
```

### 常见问题

1. **前端无法连接后端**
   - 检查后端是否启动 (端口 5780)
   - 浏览器控制台查看 CORS 错误

2. **AI 不回复**
   - 检查 DEEPSEEK_API_KEY 是否正确
   - 查看 agent.log 日志

3. **场景按钮不显示**
   - 检查 scenes.txt 配置
   - 查看 AI 是否调用了 select_scene 工具

4. **日志文件不存在**
   - 检查 logs 目录权限
   - 确认服务是否正常启动
